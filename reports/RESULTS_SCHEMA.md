# Benchmark Output Results CSV Schema

This document defines the exact schema of the consolidated benchmark output table generated by Cell 20 and exported in Cell 22 (`outputs/colab_benchmark_results.csv`).

---

### Column Dictionary

| Column Name | Data Type | Description | Valid Range / Format |
| :--- | :--- | :--- | :--- |
| `asset` | string | Dry bulk vessel class | `handy`, `supramax`, `panamax`, `cape` |
| `horizon` | string | Forecast horizon in calendar days | `7d`, `14d`, `30d` |
| `target_type` | string | Target formulation evaluated | `delta`, `pct_return`, `log_return`, `vol_normalized`, `classification` |
| `model_name` | string | Algorithm / model family name | `Persistence`, `Ridge`, `ElasticNet`, `RandomForest`, `XGBoost`, `LightGBM`, `HistGradientBoosting`, `CatBoost`, `LogisticRegression` |
| `best_hyperparameters`| string | JSON-serialized dictionary of frozen hyperparameters | e.g. `{"alpha": 1.0, "k": 50}` |
| `train_MAE` | float | Mean Absolute Error on training split ($N=1699$) | Real number $\ge 0.0$ |
| `val_MAE` | float | Mean Absolute Error across walk-forward validation ($N=480$) | Real number $\ge 0.0$ |
| `test_MAE` | float | Mean Absolute Error on locked test set ($N=402$) | Real number $\ge 0.0$ |
| `train_RMSE` | float | Root Mean Squared Error on training split | Real number $\ge 0.0$ |
| `val_RMSE` | float | Root Mean Squared Error on validation split | Real number $\ge 0.0$ |
| `test_RMSE` | float | Root Mean Squared Error on locked test set | Real number $\ge 0.0$ |
| `train_R2` | float | Coefficient of determination on reconstructed price level (Train) | $(-\infty, 1.0]$ |
| `val_R2` | float | Coefficient of determination on reconstructed price level (Val) | $(-\infty, 1.0]$ |
| `test_R2` | float | Coefficient of determination on reconstructed price level (Test) | $(-\infty, 1.0]$ |
| `directional_accuracy` | float | Ungated directional accuracy ($\text{sign}(\hat{\Delta}) == \text{sign}(\Delta)$) on Test | $[0.0, 100.0]$ (%) |
| `balanced_accuracy` | float | Macro-averaged recall across directional classes (UP, DOWN, NEUTRAL) | $[0.0, 100.0]$ (%) |
| `precision` | float | Gated directional precision on fired decision signals | $[0.0, 100.0]$ (%) or `NaN` if 0 fired |
| `recall` | float | Sensitivity / recall of true market moves identified | $[0.0, 100.0]$ (%) |
| `f1_score` | float | Harmonic mean of precision and recall | $[0.0, 100.0]$ (%) |
| `signals_fired` | integer | Number of days where gated decision signals fired on Test | $[0, N_{\text{test}}]$ |
| `test_eligible_days` | integer | Total number of valid test observations evaluated | Typically $350 - 402$ |
| `coverage_pct` | float | Ratio of signals fired to eligible test days | $[0.0, 100.0]$ (%) |
| `effective_sample_size`| float | Overlap-adjusted sample size ($N_{\text{eff}} \approx N / h$) | Real number $\ge 0.0$ |
| `ci_90_lower` | float | 5th percentile bootstrap lower bound of precision | $[0.0, 100.0]$ (%) |
| `ci_90_upper` | float | 95th percentile bootstrap upper bound of precision | $[0.0, 100.0]$ (%) |
| `exact_cp_lower` | float | Clopper-Pearson exact binomial 90% lower bound | $[0.0, 100.0]$ (%) |
| `exact_cp_upper` | float | Clopper-Pearson exact binomial 90% upper bound | $[0.0, 100.0]$ (%) |
| `overfit_flag` | string | Quantitative diagnostic of train vs val/test performance | `BALANCED`, `POSSIBLE_OVERFIT`, `UNDERFIT`, `REGIME_COLLAPSE` |
| `stability_flag` | string | Sensitivity across neighboring hyperparameters | `ROBUST_PLATEAU`, `ISOLATED_PEAK`, `FLAT_MEDIOCRE`, `UNTESTED` |
| `verdict` | string | Final objective scientific classification | `BASELINE`, `ROBUST_EDGE`, `PROMISING_INCONCLUSIVE`, `NO_RELIABLE_EDGE`, `UNSTABLE`, `OVERFIT`, `INSUFFICIENT_SAMPLE` |
| `verdict_rationale` | string | Explicit 1-2 sentence evidence-based reason for verdict | Narrative explanation |

---

### Master Verdict Definitions
1. **BASELINE**: The reference model against which alternative formulations are judged (Persistence or Ridge).
2. **ROBUST_EDGE**: Outperforms Ridge on validation AND test, maintains a stable hyperparameter plateau, has adequate coverage ($\ge 5\%$), and confidence interval lower bound $\ge 70\%$.
3. **PROMISING_INCONCLUSIVE**: Outperforms baseline on directional metrics, but sample size is small ($N_{\text{fired}} < 25$) or CI is wide ($> 20\%$). Requires additional monitoring.
4. **NO_RELIABLE_EDGE**: Performs comparably to or worse than naive persistence / majority baseline, or produces zero actionable signals.
5. **UNSTABLE**: Demonstrates high sensitivity to hyperparameter tuning (isolated spike) that collapses on nearby values.
6. **OVERFIT**: Training performance is dramatically higher than validation/test, with test $R^2 < 0$.
7. **INSUFFICIENT_SAMPLE**: Gated signal count is too small ($N_{\text{fired}} < 10$) to establish statistical validity.
